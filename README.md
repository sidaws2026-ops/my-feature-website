# GradTech Academy — Static Website

A responsive, multi-section static website concept for a software training institute.

## Files
- `index.html` — page content and forms
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation, course detail dialogs, form tabs and client-side validation

## Run locally
Open `index.html` in a modern browser. For a local development server, run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Before publishing
1. Replace GradTech Academy, sample email, phone number and Bengaluru location with your actual institute details.
2. Replace sample testimonials with verified learner reviews.
3. Connect the forms to a backend, CRM or form provider. Current forms validate inputs and show a demo confirmation only; they do not send or store submissions.
4. Replace external Unsplash image URLs with licensed/local images if required.
5. Add your privacy policy, terms, social links and real Google Maps embed/location.
6. Review course durations and curriculum against your actual batches.

The site uses Google Fonts and Unsplash-hosted images, so an internet connection is required for those assets.
